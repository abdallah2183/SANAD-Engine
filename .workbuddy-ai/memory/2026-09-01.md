## Session 2 — Triangle Rendering Milestone (COMPLETE)

**Goal:** Fix Triangle sample compile/runtime, get a real Vulkan triangle on screen, prove pixels are drawn.

### What was actually implemented/fixed
1. **Compile fix (root cause):** All engine types live in `namespace nf`; the sample used them unqualified. Rewrote `Samples/Triangle/main.cpp` inside `namespace nf::sample::triangle`.
2. **RHI interface redesign (architectural):**
   - `RenderPass::desc()` made a real virtual query returning `RenderPassDesc` by value (span re-pointed at owned storage). Fixes a dangling-span lifetime bug.
   - `PipelineDesc::render_pass` changed from a `RenderPassDesc` (borrowed span) to a `const RenderPass*`. The pipeline now uses the *actual* VkRenderPass handle instead of creating a throwaway duplicate. Removes a hidden dual-source-of-truth.
   - `ClearValue` struct replaces a flat `float[]` (the sample had passed count=1, silently clearing to wrong colour).
   - `RenderPassDesc::present_source` flag → correct `finalLayout` for on-screen vs offscreen targets.
   - `copy_texture_to_buffer` added to the RHI (needed for readback/screenshots/tests).
3. **Layout tracking:** `VulkanFramebuffer` now stores attachment textures; `begin_render_pass` updates each image's tracked layout to the pass's final layout. Without this, the first readback after a render pass treated the image as UNDEFINED and discarded it.
4. **Headless device:** `init(nullptr)` skips surface creation → GPU tests don't need a window.
5. **Vulkan loader crash (root cause):** `vkGetDeviceQueue` is a *device-level* entry point, but `create_logical_device()` called it *before* `load_device_functions()`. Moved device-function loading inside `create_logical_device()` right after `vkCreateDevice`. Also made `shutdown()` robust to a half-built device (null function-pointer guards).
6. **Validation error (semaphore reuse):** single `render_finished` semaphore raced the presentation engine. Fixed with per-swapchain-image render-finished semaphores (provably correct: an image can only be re-acquired after its present completes).
7. **Shader pipeline:** `CMake/NFShaders.cmake` compiles GLSL→SPIR-V via glslc at build time (shared by samples + tests). Samples resolve shaders via compile-time path + exe-relative fallback.
8. **Logger flush:** console sink now flushes per message so a crash can't swallow the log.
9. **RHI tests (`Tests/RHITests/test_rhi_triangle.cpp`):** offscreen render + `copy_texture_to_buffer` readback + pixel asserts (all 3 vertex colors must survive rasterization). Plus a clear-covers-target test and a mismatched-framebuffer rejection test.
