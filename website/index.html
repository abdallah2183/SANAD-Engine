مكونات ومزايا المحرك الأساسية

تم بناء كل نظام في المحرك ليعمل باستقلالية وأقصى درجات الكفاءة وتوافق خيوط المعالجة المتعددة

⚡

محرك تصيير Vulkan متطور (PBR)

مسار تصيير مؤجل (Deferred Renderer) متعدد الممرات (Depth Prepass, GBuffer, Cook-Torrance GGX Lighting, Tonemapping) مع RenderGraph ديناميكي خفيف العبء.

🧩

معمارية الكيانات والمكونات (ECS)

نظام Sparse-Set عالي السرعة مع استهلاك ذاكرة مثالي وتوافق تام لذاكرة الكاش (Cache-friendly)، يدعم الهرمية وتحويلات المشاهد وقوالب Prefabs.

🪐

محرك فيزياء حتمي (Physics Solver)

محلل تصادمات واصطدامات الأجسام الصلبة (Impulse-based with Warm Starting, SAT Narrowphase, Coulomb Friction) مع استقرار تام للخطوات الزمنية الثابتة.

🦴

نظام تحريك هيكلي (Skeletal Animation)

دعم هياكل العظام، آلة حالات التحريك (State Machine) مع الانتقالات والتلاشي والدمج (Blending)، ومولد مقاطع حركة حتمية بدون انتظار استيراد النماذج.

🔊

صوتيات ثلاثية الأبعاد واقعية

توزيع ومزج صوتي ثلاثي الأبعاد مع توهين للمسافات (Attenuation) ومحرك WASAPI مع عزل كامل في نمط Headless للاختبارات المؤتمتة.

🖥️

محرر متكامل Native ImGui Editor

محرر أصلي متكامل بنظام النوافذ القابلة للدمج (Docking)، متصفح أصول (Asset Browser)، تراجع وإعادة (Undo/Redo)، ونافذة معاينة تفاعلية وتحكم بالكاميرا.

نداء لكل مطور ومبدع عربي — لنبني "سند" معاً!

محرك سند هو مشروع عربي طموح أسسه ويقوده عبدالله ليكون سنداً حقيقياً لكل صانع ألعاب في عالمنا العربي. المحرك مصمم منذ يومه الأول ليكون قابلاً للتطوير والتوسع، ونحن نرحب بكل من يرغب في وضع بصمته: مبرمجي رسوميات، خبراء صوت، مبرمجي فيزياء، مطوري واجهات، ومصممي ألعاب. يداً بيد نصنع محركنا العربي الخاص!

البدء السريع: بناء وتشغيل المحرك

يمكنك بناء المشروع فوراً على نظام Windows باستخدام CMake و Visual Studio / Ninja

# 1. استنساخ المستودع (Clone repository)
git clone https://github.com/abdallah2183/NOVAForge-Engine.git
cd NOVAForge-Engine

# 2. بناء المحرك والأدوات (Build with batch script or CMake)
build_nf.bat

# 3. تشغيل محرر سند التفاعلي (Run SANAD Editor)
.\build\DebugNinja\bin\NOVAForgeEditor.exe

# 4. تشغيل المشغل المستقل للألعاب (Run standalone player)
.\build\DebugNinja\bin\NFPlayer.exe --frames 120 --validation
