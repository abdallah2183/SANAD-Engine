# Roadmap

[Documentation](Docs/README.md) · [Changelog](CHANGELOG.md) · [Development history](Docs/Archive/Development_History.md)

## Released baseline

**0.8.0** is the current public Windows x64 release. It includes the native editor/runtime/toolchain and the editor reliability improvements described in the [release notes](Docs/Releases/0.8.0.md).

The source contains the milestone work through Phase 131. The detailed phase ledger is preserved as [development history](Docs/Archive/Development_History.md), rather than mixed into the current roadmap.

## Areas for future proposals

| Area | Direction |
|:---|:---|
| Editor workflows | Continue reproducible fixes for authoring, scene data and undo/redo |
| Distribution | Publicly trusted Windows signing and a maintained installer path |
| Documentation | Versioned guides, current native captures and verified examples |
| Samples | Small complete projects that exercise the shipped runtime and tools |
| Platform work | Evaluate additional platforms separately from the Windows-only release contract |

These are areas for discussion, not release dates or commitments. Propose scoped work in the [issue tracker](https://github.com/abdallah2183/SANAD-Engine/issues) and follow [Contributing](CONTRIBUTING.md).
