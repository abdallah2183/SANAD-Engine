الأنظمة والمزايا الأساسية

صُمم كل نظام ليعمل باستقلالية تامة وكفاءة عالية مع جدولة متعددة الخيوط

Rendering & RHI

تصيير مؤجل حديث PBR

مسار تصيير مؤجل متعدد الممرات بمكتبة Vulkan، يشمل ممر العمق، وتوليد GBuffer، وإضاءة واقعية Cook-Torrance GGX، وإدارة ممرات بـ RenderGraph ديناميكي.

Architecture

معمارية الكيانات والمكونات (ECS)

نظام Sparse-Set متقدم يوفر أعلى سرعة وصول للذاكرة وتوافقاً كاملاً مع ذاكرة الكاش، مع دعم الهرميات وتحويلات المشاهد وقوالب Prefabs.

Simulation

محرك فيزياء حتمي

محلل تصادمات مستقل للأجسام الصلبة مبني على عزم الدفع المتسلسل (Sequential Impulses) مع خوارزميات SAT وتقليم Sutherland-Hodgman.

Jolt Physics

فيزياء Jolt المتقدمة ومركباتها

خلفية Jolt v5.6 حتمية: مركبات بعجلاتها ومحركها، قيود قابلة للنسخ بين الأجسام، راجدول، استعلامات مشهد (Raycast/Sweep/Overlap)، مستشعرات، CCD، وأشكال كبسولة/محدبة/شبكية.

Animation

نظام تحريك هيكلي

حسابات حركة العظام، آلة حالات التحريك (State Machine) مع الانتقالات والتلاشي والدمج المتعدد، وتوليد مقاطع حركية إجرائية حتمية.

Audio

صوتيات ثلاثية الأبعاد

توزيع ومزج صوتي ثلاثي الأبعاد مع نماذج التوهين وموجه WASAPI، وخط استيراد حقيقي يفك WAV وOGG وMP3 وFLAC ويربطها بالمشاهد تلقائياً.

Scripting

سكربت Lua وC#

آلة Lua 5.4 افتراضية ببيئات منفصلة لكل سكربت، مكتبة nf.*‎، ربط الكيانات، وحد تعليمات — واستضافة .NET 10 للعبة C# (Start/Update لكل كيان).

AI

ذكاء اصطناعي حتمي

بحث A*‎ شبكي بلا قص زوايا مع تنعيم رؤية، وأشجار سلوك تفاعلية بلوحة Blackboard — كلها حتمية وقابلة لإعادة التشغيل.

Gameplay

إطار لعب متكامل

وسوم هرمية واستعلامات منطقية، مهام مرحلية، مخزون، حوارات مربوطة بالوسوم، وتسجيل/إعادة تشغيل للمدخلات.

Networking

شبكات اللعب الجماعي

نقل UDP غير حاجب، قناة موثوقة (تسلسل/إقرار/إعادة إرسال)، لقطات حالة مُصدَرة، سيرفر Authoritative مع تنبؤ، ونسخ المركبات والقيود على الشبكة.

World

عالم حي: شمس وتضاريس

دورة ليل ونهار تقود الشمس والسماء، وتضاريس heightfield إجرائية بضجيج حتمي، ومولد LOD شبكي.

Pipeline

استيراد glTF حقيقي

مستورد glTF 2.0 (gltf/glb) إلى صيغة المحرك nfmesh. مع أداة NFModelImporter، وفك صور stb، ومعالج أعطال minidump.

Tools & Editor

محرر متكامل Native Editor

محرر أصلي بواجهة Dear ImGui: تقسيم نوافذ، مفتش انعكاسي، تراجع/إعادة، نافذة Profiler حية، وتعريب RTL كامل بخط أميري.

نداء للمطورين والمبدعين العرب

محرك سَنَد مشروع عربي طموح أسسه ويقوده عبدالله ليكون سنداً حقيقياً لمطوري وصناع الألعاب. صُمم المحرك بمعمارية برمجية صارمة ومفتوحة المصدر بالكامل للتوسع والتطوير المستمر. نرحب بكافة المطورين في مجالات الرسوميات، وهندسة الصوت، والمحاكاة الفيزيائية، والواجهات، والتوثيق للمشاركة في بناء هذا المشروع.

البدء السريع: البناء والتشغيل

بناء المحرك على نظام Windows باستخدام CMake و Visual Studio / Ninja

# 1. استنساخ المستودع (Clone repository)
git clone https://github.com/abdallah2183/SANAD-Engine.git
cd SANAD-Engine

# 2. بناء المحرك (Build with batch script or CMake)
build_nf.bat

# 3. تشغيل محرر سند التفاعلي (Run SANAD Editor)
.\build\DebugNinja\bin\NOVAForgeEditor.exe

# 4. تشغيل لعبة جامع المكعبات (Run the Cube Collector game)
.\build\DebugNinja\bin\NFSampleSimpleGame.exe

# 5. المحرر بالواجهة العربية (Run the editor in Arabic)
.\build\DebugNinja\bin\NOVAForgeEditor.exe --arabic
