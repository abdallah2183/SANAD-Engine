# SANAD Engine 0.9.0

## الجديد والتحسينات

- معاينة أندرويد تجريبية بصيغة APK، مع دعم اللمس المتعدد والصوت وقالب منصات 2.5D.
- خيار إنشاء معاينة أندرويد من قائمة اللعبة، مع أيقونة سند وإعدادات رسم أخف للهاتف.
- تصدير ألعاب ويندوز إلى ملف EXE واحد، وتحسين تشغيل المحرر دون نافذة أوامر.
- تحسين واجهة المحرر، وأيقونات الكائنات، وأدوات العناصر الثنائية والواجهات والبرمجة بـLua.
- إصلاحات Vulkan لتوافق أجهزة أندرويد وتحسينات للصوت والإدخال.

## حدود الإصدار

معاينة أندرويد موقعة للتجربة وليست جاهزة للنشر على المتجر. لم يكتمل ربط sprites وtilemaps وفيزياء 2D الأصلية، كما لم يكتمل دعم iOS أو تصدير AAB. قد تظهر تحذيرات Windows عند توزيع ملفات غير موقعة بشهادة عامة موثوقة.

اختُبرت معاينة المنصات على هاتف أندرويد مع اللمس والصوت وفحص Vulkan دون أخطاء؛ يختلف الأداء باختلاف الجهاز والمشهد. راجع [دليل معاينة أندرويد](../Android_Preview_Ar.md).
