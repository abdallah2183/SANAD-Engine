## مسار أ — المحرّر (بدون كود)

ابدأ هون لو بدك تفهم المحرّك قبل ما تكتب شي.

1. شغّل `SANADEditor.exe` من `build/DebugNinja/bin/`.
2. `ملف` ← `مشروع جديد` ← اختر قالبًا (`Default` أو `ThirdPerson`).
3. شغّل أوّل تجربة: اضغط **`تشغيل`** (▶) فوق. بتشوف مشهدك يشتغل.
4. عدّل شي مرئي: من شجرة المشهد انقر كيان، وحرّك موضعو من المفتش.
5. احفظ (`Ctrl+S`)، شغّل تاني، شوف الفرق.

📖 التفاصيل الكاملة: **[`Docs/Tutorial_Ar.md`](Docs/Tutorial_Ar.md)** — دليل الـ20 دقيقة
اللي يعلّمك المحرّر خطوة بخطوة.

## مسار ب — أوّل سطر كود

هون تلمس **السلوك** — تخلي كائن يتحرك بأوامر تكتبها إنت. هاد أسهل مدخل للكود.

كل مشروع جديد يجي مع سكربت جاهز ومربوط:
`Content/Scripts/example.lua` — **مربوط أصلاً** بمكعّب المشهد، فلما تضغط
"تشغيل" بتشوف المكعّب يتمايل صعودًا ونزولًا فورًا.

### أوّل شي تعلّمو: دورة السكربت

كل سكربت لازم يعرّف دالة `update(dt)`:

```lua
function update(dt)
    -- dt = الزمن منذ آخر إطار (بالثواني). هون تكتب اللي بدك يصير كل إطار.
end
```

### تحريك كائن (اللي بيعملو example.lua)

```lua
function update(dt)
    -- اقرأ موضع الكيان الحالي (self_id هو معرّف الكيان الحامل لهذا السكربت)
    local x, y, z = nf.entity_pos(self_id, self_gen)

    -- حطّه في موضع جديد
    nf.set_entity_pos(self_id, self_gen, x, y + 0.01, z)
end
```

جرّب: غيّر `y + 0.01` لأرقام مختلفة، أو خلّيه يتحرك على `x` — شوف النتيجة
فورًا وأنت تضغط "تشغيل".

### مرجع سريع للدوال (اللي رح تستعملها بالأول)

| الدالة | معناها |
|:--|:--|
| `self_id`, `self_gen` | معرّف الكيان اللي يحمل السكربت (جاهز دائمًا) |
| `nf.entity_pos(id, gen)` | ترجع `x, y, z` |
| `nf.set_entity_pos(id, gen, x, y, z)` | تحرّك الكيان لهالموضع |
| `nf.entity_alive(id, gen)` | هل الكيان موجود؟ (`true`/`false`) |
| `nf.clamp(v, lo, hi)` | حصر قيمة بين حدّين |
| `nf.lerp(a, b, t)` | تنقّل ناعم من `a` لـ `b` بنسبة `t` (0→1) |
| `print(...)` | اطبع رسالة (تظهر بالطرفية/اللوج) |
| `math.sin/cos/floor/...` | رياضيات جاهزة (للموجات والحركة) |

## مسار ج — أوّل لعبة كاملة

لما تتقن مسار "ب"، بدّك تبني لعبة حقيقية. هون ترتيب اللي تتعلمو، من الأساس
للمتقدم — **ما تقفز الترتيب**، كل خطوة تبني على اللي قبلها:

| المرحلة | تعلّم | وين تقرأ |
|:--|:--|:--|
| 1. التحريك | `update(dt)` والموضع والزمن | مسار ب فوق |
| 2. التفاعل | الأجسام والفيزياء (اصطدام، ارتداد) | المحرّر ← RigidBody/Collider |
| 3. القواعد | شروط، نقاط، فوز/خسارة | `nf.self()` + Lua العادي |
| 4. المشهد | أصوات، مواد، كيانات متعدّدة | أمثلة في `Samples/` |
